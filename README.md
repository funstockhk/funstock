# 趣仓（FUNSTOCK）独立站 + 运营管理后台 · 内部预览包 v0.1

本目录是趣仓的**独立网站与公司运营管理后台预览包**。它把公开网站、`/admin/` 管理后台、本地预览接口，以及待绑定的 Apps Script 源码放在一起，供内部上线和数据测试。

**正式流量尚未切换。** 未改 funstock.org 的 DNS，未为 GitHub Pages 设置自定义域名，未启用付费计划。现网、旧仓库和现用生产母表均未被改动。

- 公开网站：复制自 2026-11-13 只读快照的可用前端（繁体首页、`en/`、`zh-hans/`、`assets/`、资料整理页 `/c/`）。未复制现网 `CNAME`，也未沿用旧的不安全 `/admin/`。
- 管理后台：全新的 `/admin/`，统一登录门禁。登录后同一套导航：总览看板、每月经营计划、运营策划书、资料与凭证、月账与四套账、合同与发票。资料整理页仍在 `/c/`，不并入本后台。
- 后端：本地预览服务实现全部业务规则，读写本地数据存储；测试过程中已把同一批**虚构**测试行写入新 Google 表，测试文件放入新专属 Drive 文件夹。本地服务与 Google 表不是实时双向同步。Apps Script 源码已备好，**尚未绑定、尚未部署**。
- 独立仓库目标位置：https://github.com/funstockhk/funstock（Private）。本包是干净的站点树，供随后由他人推送。本次未向 GitHub 推送。

## 如何启动预览

在本目录执行：

```bash
./start-preview.sh
```

默认监听 `http://127.0.0.1:8787/`。

- 公开站：http://127.0.0.1:8787/
- 后台登录：http://127.0.0.1:8787/admin/login.html
- 测试口令只写在本机 `credentials.local.md`（已被 `.gitignore` 排除），不要写入网页、表格正文或本说明。

未登录访问 `/admin/` 下的栏目会被拒绝。授权用户表缺失时也会拒绝，不会默认放行。

## 目录结构

- `site/` 公开网站与新 `/admin/`
- `server/` 本地预览接口（与后台约定的唯一 API）
- `apps-script/` 待绑定到新表的 Apps Script 源码
- `data/store.json` 本地数据（含已跑通的 2026-10 测试月）
- `screenshots/` 后台页面截图
- `对内_实现说明_v0.1_20261113.md` 启动方式、脚本绑定方法和已知限制（一页）
- `对内_测试记录_v0.1_20261113.md` 与 PDF 测试记录

## 不要做的事

不要把本预览宣布为已上线系统，不要改 DNS，不要把现用母表数据迁入，不要在网页或表格里写入明文密码。
